# Filmes — catálogo pessoal

Um aplicativo web progressivo (PWA), responsivo e em português, para explorar filmes, séries e animes, pesquisar títulos, filtrar por categoria e guardar favoritos no navegador.

## Abrir, instalar ou baixar

Abra o app publicado em [amandab171207.github.io/Filmes](https://amandab171207.github.io/Filmes/) em qualquer dispositivo e use **Instalar app** (ou o menu do navegador para adicionar à tela inicial). Para baixar os arquivos, use **Code → Download ZIP** no repositório público; extraia o ZIP e abra `index.html`.

## O que está incluído

- Categorias: Clássicos, Anos 2000, Animes, Séries, Ação, Comédia, Ficção Científica, Terror e Romance.
- Busca por título, ano e categorias.
- Biblioteca pessoal e lista “Já assisti”, salvas localmente no dispositivo.
- Modal com sinopse, detalhes e atalhos de busca nos catálogos de Netflix, Prime Video, Disney+, Max, Apple TV+, Paramount+, Globoplay, Crunchyroll e MUBI.
- Assistente local de recomendações por estilo e pelo conteúdo da biblioteca.
- Layout responsivo para computador, tablet e celular.
- Instalação como PWA e cache da interface para uso offline após a primeira visita.

Imagens públicas e a fonte tipográfica são carregadas pela internet. A biblioteca e o histórico ficam salvos em cada navegador e não sincronizam entre dispositivos. As recomendações são calculadas no app por categorias e não usam um modelo generativo. Os atalhos de streaming abrem a busca do título no serviço, mas não confirmam disponibilidade.
